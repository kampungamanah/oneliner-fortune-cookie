# oneliner-fortune-cookie

A fortune cookie, cracked open for a developer: one short line of wisdom about the code we inherit, the code we curse, and the people who wrote it before us.

`main.ts` writes that line to `/output/entry.txt`:

> The legacy code you curse today was written by someone who, like you, was only trying to go home.

## Run it

    node main.ts

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` if that variable is set, and to `/output/entry.txt` otherwise — just the line itself, no trailing newline, 97 characters.
